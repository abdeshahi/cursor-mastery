# CTTEL News Bot

بات خودکار برای دریافت آخرین اخبار از منابع تخصصی موبایل و tech، ترجمه حرفه‌ای به فارسی، و انتشار در کانال تلگرام.

## منابع پیش‌فرض

| منبع | نقش | توضیح |
|---|---|---|
| **GSMArena** | مشخصات فنی | مرجع اصلی specs، مقایسه و اخبار سریع موبایل |
| **Android Authority** | بررسی تخصصی | پوشش اندروید، ویدیو و راهنمای خرید |
| **PhoneArena** | بررسی تخصصی | بررسی عملی، مقایسه و امتیازدهی |
| **The Verge** | خبر گجت | خبر سریع و تحلیل محصول |
| **Engadget** | خبر گجت | خبر سریع و تحلیل محصول |
| **CNET** | راهنمای خرید | بررسی مصرف‌کننده |
| **TechRadar** | راهنمای خرید | بررسی و راهنمای خرید |
| **Android Police** | ليك | لیك، تیزر و خبر قبل از رونمایی |
| **9to5Google** | خبر گجت | اکوسیستم گوگل و پیکسل |
| **9to5Mac** | اکوسیستم اپل | اخبار سخت‌افزار و نرم‌افزار اپل |
| **MacRumors** | اکوسیستم اپل | شایعات و پوشش رونمایی اپل |
| **DXOMARK** | تست آزمایشگاهی | تست دوربین، صدا و نمایشگر |
| **Notebookcheck** | تست آزمایشگاهی | بررسی عمیق نمایشگر، عملکرد و باتری |

> برای مشخصات فنی همیشه GSMArena مرجع اول است؛ برای بررسی واقعی PhoneArena یا Android Authority.

## قابلیت‌ها

- ۱۳ منبع RSS تخصصی (قابل تغییر با `FEED_URLS`)
- ترجمه تخصصی با OpenAI-compatible API (با آگاهی از نقش هر منبع)
- جلوگیری از ارسال تکراری
- ارسال عکس شاخص
- زمان‌بندی cron + health check روی پورت 3002

## راه‌اندازی

```bash
cp .env.example .env
pnpm install
pnpm dev
```

### متغیرهای مهم

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن بات (@BotFather) |
| `CHANNEL_ID` | `@channel` یا `-100...` |
| `OPENAI_API_KEY` | کلید API ترجمه |
| `FEED_URLS` | جایگزین منابع پیش‌فرض (با کاما) |
| `POLL_CRON` | زمان‌بندی (پیش‌فرض: هر ۳۰ دقیقه) |
| `TELEGRAM_PROXY` | پروکسی VPS (مثلاً `http://127.0.0.1:8118`) |

## Deploy

```bash
VPS_PASSWORD=... python3 deploy/vps-deploy.py
```
