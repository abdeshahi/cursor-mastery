# Mobinnet + V2Ray OpenWrt speed kit

Persian guide and one-shot OpenWrt optimizer for Linksys EA8300 / `ipq40xx` with Mobinnet and V2Ray/Xray.

- Script: [`openwrt/optimize-mobinnet-v2ray.sh`](openwrt/optimize-mobinnet-v2ray.sh)
- Guide (FA): [`openwrt/README-FA.md`](openwrt/README-FA.md)

Run the script **on the router** over SSH as root. This cloud environment cannot reach your home LAN.
